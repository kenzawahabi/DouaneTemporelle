# Douane Temporelle

Mini-projet (DS 1) de developpement Mobile, 3ème BI - FSEGT. Application Android (Java) qui simule un poste de douane pour les voyageurs du temps.

## Équipe

- **Takwa Ben Salem (A04)** : Activité 1 et layout XML de l'activité 2
- **Kenza Wahabi (A03)** : Activité 3 et code Java de l'activité 2

## Les 3 écrans

1. **MainActivity** : formulaire (nom, année de naissance, année de destination, motif en boutons radio).
2. **VerificationActivity** : passeport temporel avec l'âge temporel. Le bouton « Approuver » est désactivé si le motif est « Modification du passé » et que la différence d'années est un nombre premier.
3. **ResultActivity** : fond vert (approuvé) ou rouge (refusé), message personnalisé, et bouton « Nouveau voyageur » qui ferme les activités précédentes.

## Technologies utilisées

- **Java**
- **Android Studio**
- **XML**
- **Git et GitHub.**
